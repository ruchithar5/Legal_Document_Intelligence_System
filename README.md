# ⚖️ Legal Document Intellegence system

An AI-powered Legal Document Analysis System that automatically classifies, summarizes, and extracts key information from legal documents such as Agreements, NDAs, Employment Contracts, and Lease Agreements.

---

## 🚀 Project Overview

Legal documents are often lengthy and complex. This project simplifies them by:

- 📄 Accepting PDF uploads or text input
- 🏷 Automatically identifying document type
- 🧾 Generating a structured summary
- 🔍 Extracting key details such as:
  - Parties involved
  - Date of agreement
  - Purpose
  - Important clauses

The system is designed to assist students, startups, HR teams, and individuals in quickly understanding legal documents.

---

## 🛠 Technologies Used

- Python
- Streamlit (Frontend UI)
- NLP-based Text Classification
- Text Summarization Model
- PDF Text Extraction Libraries

---

## ⚙️ How It Works

1. User uploads a legal document (PDF) or pastes text.
2. The system extracts text from the document.
3. NLP model analyzes the text.
4. The system:
   - Predicts document type
   - Generates a summary
   - Extracts structured legal information
5. Results are displayed in a clean and user-friendly interface.

## 📌 Installation & Setup

1. Clone the repository:

https://github.com/ruchithar5/Legal_Document_Intelligence_System.git


2. Navigate into the folder:

cd Legal_Document_Intelligence_System

3. Install dependencies:

pip install -r requirements.txt

4. Run the application:

streamlit run app.py
